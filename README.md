# CORPORATE ENTROPY / 架空企業経営シム

数字は成長する。あなたの手を離れて。

PCブラウザ向けの経営シミュレーション。日本語、ダークテーマ、外部ライブラリ・外部通信なし。HTML/CSS/JavaScriptのみで、創業から倒産・CEO退任までプレイできます。

## 遊ぶ

GitHub Pagesで公開後、**https://kumo-01.github.io/game1/** を開いて遊べます。プレイヤーのPCでNode.jsやローカルサーバーを起動する必要はありません。

### GitHub Pagesの初回設定

1. リポジトリの **Settings → Pages → Build and deployment** を開きます。
2. **Source** に **GitHub Actions** を選択します。
3. **Actions → Deploy game to GitHub Pages → Run workflow** を実行します。
4. `build` と `deploy` が成功すると上記URLで公開されます。以後は `main` の更新時に自動でテスト・公開されます。

公開設定： https://github.com/kumo-01/game1/settings/pages  
デプロイ状況： https://github.com/kumo-01/game1/actions/workflows/pages.yml

HTML/CSS/JavaScriptの参照はすべて相対パスで、GitHub Pagesの `/game1/` 配下でも動作します。公開対象はゲーム用の7ファイルだけで、テストやローカルサーバーは配信しません。`.nojekyll` でJekyllによる処理を無効にしています。

保存はブラウザのlocalStorageを利用します。同じ端末・ブラウザで再開でき、GitHubへのログインはプレイに不要です。localhostでのセーブはGitHub Pagesには引き継がれません。

### 開発用のローカルプレビュー（任意）

`index.html` を直接開くか、Node.js 18以上で以下を実行してください。

```sh
npm start
```

http://127.0.0.1:4173 を開きます。依存パッケージのインストールは不要です。

## 経営の基本

- **初心者モード**：資金・売上・利益の違い、34個の表示指標、全18アクション、判断の長期的な影響を平易な言葉で説明。今の危険な連鎖に応じた助言を表示し、詳しい指標は展開して閲覧できます。
- **ガチ勢モード**：従来の高密度ダッシュボードを維持。説明を省き、30指標を一覧表示します。どちらも数値・難易度・乱数は同じです。
- 創業画面または右上のメニューでモードを切り替え可能。途中で変えても会社はリセットされません。
- 再生中にイベント・買収・遊び方の画面を開くと一時停止し、判断・閉じる操作の後に元の速度で自動再開。元から停止中なら停止を維持します。倒産・新規創業・タブ非表示の後には勝手に再開しません。
- **効果音**：操作、週次決算、判断通知、経営終了の音をブラウザ内で合成。最初のクリックまたはキー操作で有効になります。右上でミュート・音量を調整できます。モードと音設定は会社のセーブとは別に保存します。
- 創業方針と会社名を選択。資本金1,000万円、社員6名から開始。
- 1週につき決裁3枠。再生/停止と1週送り、1×/2×/5×速度を切り替え可能。
- 広告・福利厚生・給与・設備維持・利息は継続費用。予測利益と資金を確認する。
- 需要、生産力、在庫、負荷、障害、返品、満足、信用が連動。給与削減は士気・忠誠・退職に影響する。
- 12名で部署KPI、20名で管理職・役員・委任・M&A、60名で政治と決裁枠2、120名で株主・自律決裁。
- 法務社員はリスク、経理社員は管理効率、人事社員は応募数、営業・広報社員は需要、開発社員は技術成長に貢献。
- 20種の判断イベント。不具合公表、内部告発、監査、規制、景気、離職、広告炎上など。イベント中は時間停止。
- 研究開発や隠蔽には遅延効果。進行中案件と年表で確認。
- 4社のAI競合が価格・採用・製品を更新。倒産、急成長、企業間買収も発生。
- 買収では人材・技術・設備・ブランドと同時に負債・統合費用・文化摩擦・退職を引き継ぐ。
- 委任は資金と決裁枠を消費。巨大組織では手動方針でも役員が動く。
- 資金0未満、信用5以下、法務99以上で経営終了。120名以上で任意のCEO退任、520週で任期満了。
- 終了後も年表、最高売上、最大社員、炎上、買収、離職、歴代CEOを閲覧可能。新規創業で再挑戦。
- セーブは同じブラウザ・同じURLに自動保存。再開で乱数状態も復元。
- Spaceで再生/停止、Nで次の週。タブを非表示にすると停止。

## 構成と検証

- `engine.js`：画面から独立した、シード付き乱数による経営シミュレーション
- `app.js`：ダッシュボード、操作、イベント、Canvasグラフ、保存
- `ui-tools.js`：一時停止と再開、Web Audioの効果音、初心者向け解説
- `style.css`：PC中心のレスポンシブUI
- `modes.css`：モード選択・初心者向けの説明表示・音量コントロール
- `server.js`：localhost専用の静的プレビューサーバー
- `tests/engine.test.js`：KPI連鎖、判断の遅延効果、委任、買収、保存再現、各終了条件、100シードの長期試験
- `tests/ui-tools.test.js`：再開の状態遷移、終了時の停止、音量・ミュート・音ノードの寿命、解説と経営ロジックの独立性

```sh
npm test
npm run check
```

これは架空の経済を抽象化したプロトタイプです。謎KPIのうち、会議密度と無意味なKPIは管理効率へ実際に作用し、社内空気は士気の状態表示です。部署や社員はすべて実際のシミュレーション状態から表示します。CEOカリスマは業績・士気で変動する状態表示、スライド枚数は会議の状態表示です。文化は生産力、需要、ストレス、満足、法務、イベント頻度に影響します。創業方針は社員特性とイベント傾向にも影響します。
