# CORPORATE ENTROPY / 架空企業経営シム

数字は成長する。あなたの手を離れて。

PCブラウザ向けの経営シミュレーション。日本語、ダークテーマ、外部ライブラリ・外部通信なし。HTML/CSS/JavaScriptのみで、創業から倒産・CEO退任までプレイできます。

## 遊ぶ

GitHub Pagesで公開後、**https://kumo-01.github.io/game1/** を開いて遊べます。プレイヤーのPCでNode.jsやローカルサーバーを起動する必要はありません。

### GitHub Pagesの初回設定

1. リポジトリの **Settings → Pages → Build and deployment** を開きます。
2. **Source** に **GitHub Actions** を選択します。
3. **Actions → Deploy game to GitHub Pages → Run workflow** を実行します。
4. `build` と `deploy` が成功すると上記URLで公開されます。以後は `main` の更新時に自動でテスト・公開されます。

公開設定： https://github.com/kumo-01/game1/settings/pages  
デプロイ状況： https://github.com/kumo-01/game1/actions/workflows/pages.yml

HTML/CSS/JavaScriptの参照はすべて相対パスで、GitHub Pagesの `/game1/` 配下でも動作します。公開対象はゲーム用の11ファイルだけで、テストやローカルサーバーは配信しません。`.nojekyll` でJekyllによる処理を無効にしています。

保存はブラウザのlocalStorageを利用します。同じ端末・ブラウザで再開でき、GitHubへのログインはプレイに不要です。localhostでのセーブはGitHub Pagesには引き継がれません。

### 開発用のローカルプレビュー（任意）

`index.html` を直接開くか、Node.js 18以上で以下を実行してください。

```sh
npm start
```

http://127.0.0.1:4173 を開きます。依存パッケージのインストールは不要です。

## 経営の基本

- **初心者モード**：資金・売上・利益の違い、34個の表示指標、全18アクション、判断の長期的な影響を平易な言葉で説明。今の危険な連鎖に応じた助言を表示し、詳しい指標は展開して閲覧できます。
- **ガチ勢モード**：従来の高密度ダッシュボードを維持。説明を省き、30指標を一覧表示します。どちらも数値・難易度・乱数は同じです。
- 創業画面または右上のメニューでモードを切り替え可能。途中で変えても会社はリセットされません。
- 再生中にイベント・買収・遊び方の画面を開くと一時停止し、判断・閉じる操作の後に元の速度で自動再開。元から停止中なら停止を維持します。倒産・新規創業・タブ非表示の後には勝手に再開しません。
- **効果音**：操作、週次決算、判断通知、経営終了の音をブラウザ内で合成。最初のクリックまたはキー操作で有効になります。右上でミュート・音量を調整できます。モードと音設定は会社のセーブとは別に保存します。
- **BGM**：ドラム・ベース・アルペジオ入りのオリジナル曲をブラウザ内で合成。効果音とは別にミュート・音量を保存し、会社の危機で曲調が変化します。タブ非表示で停止します。
- **みんなの声**：社員専用・インターネットの閲覧専用SNS。給与、ストレス、顧客満足、障害などに応じた架空の投稿を毎週生成し、各120件をセーブに保存します。
- **会社の様子**：6部署、サーバー室、工場・倉庫、会議室、休憩室をマップで表示。実際の社員、ストレス、負荷、在庫に連動して色・設備・雰囲気が変化し、部屋を選ぶと詳細を確認できます。
- 創業方針と会社名を選択。難易度に応じた資本金700〜1,800万円、社員6名から開始。
- 1週につき決裁3枠。再生/停止と1週送り、1×/2×/5×速度を切り替え可能。
- 広告・福利厚生・給与・設備維持・利息は継続費用。予測利益と資金を確認する。
- 需要、生産力、在庫、負荷、障害、返品、満足、信用が連動。給与削減は士気・忠誠・退職に影響する。
- 12名で部署KPI、20名で管理職・役員・委任・M&A、60名で政治と決裁枠2、120名で株主・自律決裁。
- 法務社員はリスク、経理社員は管理効率、人事社員は応募数、営業・広報社員は需要、開発社員は技術成長に貢献。
- 40種の判断イベント。不具合公表、内部告発、監査、規制、景気、離職、広告炎上など。イベント中は時間停止。
- 研究開発や隠蔽には遅延効果。進行中案件と年表で確認。
- 4社のAI競合が価格・採用・製品を更新。倒産、急成長、企業間買収も発生。
- 買収では人材・技術・設備・ブランドと同時に負債・統合費用・文化摩擦・退職を引き継ぐ。
- 委任は資金と決裁枠を消費。巨大組織では手動方針でも役員が動く。
- 資金0未満、信用5以下、法務99以上で経営終了。120名以上で任意のCEO退任、520週で任期満了。
- 終了後も年表、最高売上、最大社員、炎上、買収、離職、歴代CEOを閲覧可能。新規創業で再挑戦。
- セーブは同じブラウザ・同じURLに自動保存。再開で乱数状態も復元。
- Spaceで再生/停止、Nで次の週。タブを非表示にすると停止。

## 構成と検証

- `engine.js`：画面から独立した、シード付き乱数による経営シミュレーション
- `app.js`：ダッシュボード、操作、イベント、Canvasグラフ、保存
- `ui-tools.js`：一時停止と再開、Web Audioの効果音、初心者向け解説
- `company-life.js`：BGM、経営状態に連動するSNS、会社マップの状態
- `life.css`：SNS・マップ・BGMの表示
- `tests/company-life.test.js`：投稿の再現性・秘匿・保存、マップと社員数、BGMのスケジュール・停止
- `style.css`：PC中心のレスポンシブUI
- `modes.css`：モード選択・初心者向けの説明表示・音量コントロール
- `server.js`：localhost専用の静的プレビューサーバー
- `tests/engine.test.js`：KPI連鎖、判断の遅延効果、委任、買収、保存再現、各終了条件、100シードの長期試験
- `tests/ui-tools.test.js`：再開の状態遷移、終了時の停止、音量・ミュート・音ノードの寿命、解説と経営ロジックの独立性

```sh
npm test
npm run check
```

これは架空の経済を抽象化したプロトタイプです。謎KPIのうち、会議密度と無意味なKPIは管理効率へ実際に作用し、社内空気は士気の状態表示です。部署や社員はすべて実際のシミュレーション状態から表示します。CEOカリスマは業績・士気で変動して需要に影響します。スライド枚数は管理効率を削ります。文化は生産力、需要、ストレス、満足、法務、イベント頻度に影響します。創業方針は社員特性とイベント傾向にも影響します。

## 拡張した経営ルール

- 採用先はアクション一覧上部の「採用先を変更」から専用画面で選択します。選択は無料で決裁枠を消費せず、採用ボタンに選んだ部署を表示します。
- 創業時の難易度：めちゃかんたん／かんたん／ふつう／むずかしい／はげしい／げきむず。初期資金、緊急判断の発生確率・間隔、法務負担が変わります。説明モードとは別です。以前のセーブは「ふつう」を引き継ぎます。
- 難易度順の緊急判断基礎確率は9%／22%／48%／62%／78%／94%。判断後に10／7／3／2／1／0週＋0〜2週の待機があり、発生機会にはカオス文化の補正が入ります。高負荷・疲労・法務などでイベントの種類も偏ります。
- 競合の倒産・買収による退出は8週間表示します。その後、新しい名前・ID・産業・能力を持つ企業が参入。旧企業の記録は年表に残ります。
- 景気・信用・顧客満足・開発比率・法務人員・技術・管理効率・士気がアクションの効き目を変え、さらに乱数で成果が変動。実効倍率はログと直前アクションに表示します。融資額、返済額、採用人数、継続予算など契約部分は固定です。
- 株式会社／非株式会社を創業時に選択。非株式会社は株主要求を受けず、80万円で株式会社へ移行可能です。株式会社・20名・信用60以上・200万円で株式公開。600万円を調達（差引400万円）、持分75%、開示費用8万円/週、株主要求が発生します。
- 「株式市場」で会社資金による競合株の売買が可能。決裁枠1・手数料1%。保有株の評価額は現金ではありません。倒産はゼロ、競合間買収は株価で、自社買収は株価の80%で清算します。新規参入企業へ旧保有株を引き継ぎません。
- ドラム（キック・スネア・ハイハット）、ベース、旋律をWeb Audioで合成。効果音も和音・ファンファーレを追加。外部音源は不要です。
- 創業・成長・最高売上の節目・上場に紙吹雪、通常の操作には小さな粒子。右上の「演出」でオン／オフでき、端末の動きを減らす設定にも対応します。
- 緊急判断を20種追加：供給停止、電力高騰、誤送信、水漏れ、採用競争、偽アカウント、返品窓口、税務、クラウド値上げ、配送停止、デモ故障、引き抜き、支払い延期、契約違反、アクセス権限、体調不良、レビュー動画、競合新技術、席不足、検品漏れ。
- `expansion.js`：難易度、追加イベント、状況によるアクション補正、株価の共通計算。`expansion.css`：採用選択、株式画面、紙吹雪。
- `tests/expansion.test.js`：6難易度の発生差、20イベントの両選択肢、8週の再参入、株取引、株式会社化・上場、成果補正と保存互換性。
